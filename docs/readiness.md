# Контроль требований к 24 октября

Это карта требований исходного документа, а не подтверждение их выполнения. Предметные черновики и локальный CLI подготовлены по теме intelligent intersection traffic management. Сведения о фактических проверках находятся в verification-status.md, внешние и эмпирические действия — в ../OPEN_ITEMS.md.

| Материал | Минимальное содержание | Подтверждение готовности |
|---|---|---|
| README | Название, проблема, пользователи, результаты, команда, руководитель, границы, статус, технологии, ссылки, запуск и тесты при наличии кода | Все сведения заполнены и проверены |
| Предложение и границы | Цель, задачи, результаты, инженерная сложность, что входит и не входит | Согласованное описание |
| Актуальность | 3–5 обсуждений с представителями пользователей либо содержательная договорённость с реальным заказчиком | Анонимизированные записи; факты отделены от гипотез |
| Обзор литературы | Минимум 12 содержательно использованных источников, включая 8 научных; критический разбор и таблица | Проверенные ссылки и связь выводов с проектом; для быстро меняющейся темы основа за последние 5 лет |
| Аналоги | 3–5 систем, 6–10 общих критериев; меньшее число обосновано | Возможности подтверждены источниками |

| Требования | Функциональные, нефункциональные, приоритеты и критерии приёмки | Каждое обязательное требование проверяемо |
| Архитектура | Контекст, Use Case, черновой Component Diagram и описание | Редактируемые исходники и читаемые экспорты согласованы с требованиями |
