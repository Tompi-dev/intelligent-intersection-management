# Шпаргалка: запуск и показ без технического опыта

## А. Что установить

На этом Mac необходимый Python уже есть. Скрипт выбирает Python 3.10+; проверенный запуск использовал 3.12.14. В `pyproject.toml` указано `dependencies = []`: сторонних зависимостей нет.

**Не нужны:** `pip install`, `npm install`, React, Node.js, OpenCV, PyTorch, YOLO, SUMO, FastAPI, Docker, API-ключи и платные сервисы для текущей демонстрации. Будущий CV/SUMO-стек устанавливается отдельно, когда появится соответствующая реализация.

Не запускайте просто `python3`, если это системный Python 3.9. На этом Mac используйте `run_demo.command`: он сам выберет подходящий установленный интерпретатор. На другом компьютере нужен Python 3.10+; никакой файл проекта не устанавливает его автоматически.

## В. Что нажать на показе

1. Вкладка **Intersection monitor**.
2. Feed = **Fresh observations**.
3. Preset = **East–west peak**.
4. **Reset**: восстановить время; preset и timing сами по себе Reset не меняет.
5. Скорость **4×**, **Start run**.
6. При стандартных настройках: 10 с — NS жёлтый, 13 с — все красные, 15 с — EW зелёный.
7. **Pause** → **North–south peak** → продолжить: показать влияние изменённых очередей.
8. **Pause** → **Missing observations** → **Step +1 s**: показать Fallback.
9. **Run evidence** → **Export run**: сохранить журнал.

## Г. Как вернуть стандартные настройки

Открыть **Run configuration**, ввести:

| Поле | Значение |
|---|---|
| Minimum green | 10 |
| Maximum green | 45 |
| Yellow clearance | 3 |
| All-red clearance | 2 |
| Fallback green | 20 |
| Stale after | 2 |
| Queue hysteresis | 2 |

Нажать **Apply settings & reset run**. Затем вернуть Fresh observations / East–west peak и нажать Reset. Изменённые настройки применяются к новому журналу. Предыдущий нужный журнал сначала экспортировать.

## Д. Частые проблемы

| Что видите | Что сделать |
|---|---|
| Старая картинка без кнопок | Открыть порт **8766 без `.svg`**, а не 8765/02-monitor.svg |
| После изменения цвета старая тема | Обновить страницу: ⌘⇧R; текущий журнал сначала экспортировать |
| Страница не открывается | Проверить терминал: сервер должен продолжать работать |
| Python disconnected | Убедиться, что запущен новый сервер через run_demo.command; открыть его адрес и обновить страницу |
| Address already in use | Если нужное демо уже работает — пользоваться им; иначе остановить свой прежний сервер через Ctrl+C |
| Порт занят другим приложением | `./run_demo.command --serve --port 8767`, открыть http://127.0.0.1:8767/ |
| Свет не переключается сразу | Это ожидаемо: минимальный зелёный 10 с, затем жёлтый 3 с и все красные 2 с |
| Таймер не идёт | Нажать Start run; в Pause время остановлено |
| Пишет Fallback | Выбрана потеря/заморозка наблюдений; вернуть Fresh observations и сделать шаг |
| Очереди не уменьшаются сами | Они вводятся вручную; модель движения и автоматический подсчёт видео пока не подключены |
| Run limit reached | Экспортировать JSON и нажать Reset; предел — 1800 записей |
| После обновления пропал журнал | Журнал хранится в памяти страницы. Для сохранения нужен Export run |
| Invalid settings | Все интервалы положительные; min ≤ fixed ≤ max; hysteresis — целое ≥ 0 |

Не завершайте произвольные процессы и не удаляйте файлы ради освобождения порта. Если не уверены, используйте другой порт.

## Е. Запасной показ без браузера

В отдельном терминале в папке проекта:

```sh
./run_demo.command --port 8766
```

Наличие аргумента `--port` без `--serve` запускает проверки и текстовый пример, затем программа завершается. Будут показаны 20 тестов и таблица фаз. Это нормальное завершение, не ошибка.

Для отдельного запуска только контроллера на этом Mac:

```sh
'/Users/tomiris_k/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3' -m src.controller --input prototype/sample_observations.json
```

Для отдельных тестов:

```sh
'/Users/tomiris_k/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3' -m unittest discover -s tests -v
```

Этот абсолютный путь относится только к данному Mac. На другом компьютере используйте его установленный Python 3.10+.

Если браузер не доступен, покажите сохранённые SVG/PNG как дизайн и терминальную таблицу как работающий код. Не называйте картинку живым интерфейсом.

## Ж. Остановить и запустить снова

В терминале сервера нажать **Ctrl+C**. Для повторного запуска снова выполнить `./run_demo.command` и обновить страницу. Страница без работающего сервера не сможет получать решения Python.

## З. Речь в одной минуте

> Мы исследуем управление одним упрощённым перекрёстком с использованием оценки очередей. Сейчас реализован интерфейс и Python-контроллер на синтетических наблюдениях. На примере 5 машин NS против 27 EW видно, что алгоритм учитывает спрос, но сначала выдерживает минимальный зелёный, жёлтый и интервал всех красных. При потере наблюдений используется фиксированный резервный режим. В наборе 20 проходящих тестов, решения можно экспортировать. Детекция машин по видео и проверка транспортного эффекта в SUMO — следующие этапы; снижение пробок пока не заявляем.

## И. Словарь для объяснения простыми словами

| Термин | Простое объяснение |
|---|---|
| Frontend | Экран, кнопки и поля, которые видит человек |
| Backend | Python-программа, которая получает данные и рассчитывает ответ |
| API | Согласованный способ передать вопрос программе и получить ответ |
| JSON | Текстовый формат данных: имена полей и значения, например число машин |
| NS / EW | Север–юг / восток–запад, две группы разрешённых направлений |
| Фаза | Какой сигнал сейчас действует для движения |
| Гистерезис | Запас перед сменой решения, чтобы не реагировать на слишком малую разницу |
| Fallback | Заранее определённый запасной режим при отсутствии свежих данных |
| Детектор | Будущий компонент, который находит машины на кадре |
| Трекер | Будущий компонент, который сопоставляет одну машину между кадрами |
| Baseline | Базовый способ, с которым сравнивают новый алгоритм |
| Unit-тест | Автоматическая проверка конкретного случая работы кода |
| PR / ревью | Запрос на включение изменения и его проверка другой участницей |
| Git tag | Имя, закреплённое за конкретной сдаваемой версией |
