# Как использовать пакет

Основная документация на английском, как исходное задание и название темы. Написание Intelligent в заголовке исправлено. Начните с README и docs/INDEX.md. Консолидированный Word на 25 страницах и редактируемая презентация на 14 слайдах находятся в deliverables/.

Запускаемый пример: из корня проекта выполните python3 -m src.controller --input prototype/sample_observations.json. Проверки: python3 -m unittest discover -s tests -v. Макеты экранов и схемы открываются в браузере как обычные SVG. Это локальные материалы; сайт не опубликован.

Документы описывают исследовательский прототип одного перекрёстка, проверяемый в симуляции. Цели точности и эффективности ещё предстоит подтвердить экспериментами. Реальные интервью, доступы, история команды и отзывы не подменены сгенерированными данными. Список оставшихся действий находится в OPEN_ITEMS.md.

План до 24 октября 2026 года предложен на основе текущей даты. Уточните его у руководителя, если задание относится к другому учебному календарю.

Исходная локальная папка содержит Git с веткой main. Удалённый репозиторий проекта: https://github.com/Tompi-dev/intelligent-intersection-management. Теги сдачи не созданы. В ZIP включены исходные файлы без служебной папки .git. После распаковки выполните git init -b main, если начинаете новый репозиторий, либо перенесите файлы в существующий общий репозиторий.
