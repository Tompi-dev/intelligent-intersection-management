# Интерактивная демонстрация к 24 октября 2026

Работающий локальный интерфейс связан с настоящим Python-контроллером. Вы редактируете синтетические очереди N/S/E/W; сервер возвращает фазу, группу, режим и причину. Цвета сигналов, журнал и шкала обновляются по ответу сервера. Камера и SUMO пока не подключены. Положения машин иллюстративны; уменьшение пробок не измерялось.

## Запуск

В терминале VS Code:

```sh
cd '/Users/tomiris_k/Downloads/files (7)/diploma-pre-defense'
./run_demo.command
```

Откройте **http://127.0.0.1:8766/**. Это новый адрес приложения; старый `02-monitor.svg` показывает только макет.

Скрипт выбирает установленный Python 3.10+, выполняет 20 тестов и сверяет JSON-пример с эталоном. Затем запускается сервер. Пакеты pip/npm не требуются; интернет для интерфейса не нужен. Терминал оставьте открытым; остановка — Ctrl+C. Если демо уже запущено, используйте открытую страницу; перед перезапуском остановите прежний процесс.

Если порт занят, выполните `./run_demo.command --serve --port 8767` и откройте порт 8767. На другом компьютере с Python 3.10+ используйте `python3 demo.py --serve`. Только проверки, без сервера: `./run_demo.command --port 8766`.

## Показ на 3–4 минуты

1. Откройте **Intersection monitor**: статус **Python controller connected**. Начальные очереди N=3, S=2, E=15, W=12 — вводимые числа, не результат видеоаналитики.
2. Выберите Playback **4×**, нажмите **Start run**. Каждый шаг — секунда сценария; ускорение меняет только скорость показа.
3. При t=10 с NS переходит в жёлтый, при t=13 с обе группы красные, при t=15 с EW получает зелёный. Объясните по **Decision inspector** и журналу.
4. Нажмите **Pause**, выберите **North–south peak**, продолжите. После минимального зелёного начнётся переход к направлению с большей очередью.
5. Выберите **Missing observations**. Режим станет **Fallback**; переходные интервалы сохранятся. **Freeze last observation** демонстрирует устаревание данных.
6. На **Run configuration** измените интервалы и нажмите **Apply settings & reset run**. Это новый журнал с новыми настройками. Нужный прежний журнал сначала экспортируйте.
7. На **Run evidence** покажите график введённых очередей и ограничения. **Export run** сохраняет JSON с настройками, входами, решениями и пометкой об источнике. Reset и обновление страницы очищают текущий журнал в памяти браузера.

## Что реализовано

- `web/index.html`, `style.css`, `app.js`: интерфейс и отображение ответов.
- `src/web_demo.py`: GET /api/health, POST /api/replay, статические файлы.
- `src/controller.py`: единственный источник правил управления. В JavaScript нет второго алгоритма переключения.
- Каждый запрос передаёт историю текущего браузера и повторяет её в новом контроллере: вкладки не смешивают состояния. Предел — 1800 записей, затем экспорт и сброс.
- Экспорт позволяет повторить использованные наблюдения, но не доказывает эффективность в дорожном движении.
